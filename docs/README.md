# Screenshots

The main `README.md` references four images from this folder. Drop your own captures in here with
these exact filenames and they'll appear automatically:

| Filename | What to capture | Suggested size |
|---|---|---|
| `screenshot-desktop.png` | The full dashboard at desktop width | ~1440px wide |
| `screenshot-mobile.png` | The dashboard on a phone viewport | ~390px wide |
| `screenshot-chart.png` | The temperature chart card, ideally with the tooltip open | ~1200px wide |
| `screenshot-search.png` | The search box with the city dropdown open (try "London") | ~1200px wide |

## Taking them

Run both servers (see the main README), open <http://localhost:5173>, then:

- **macOS** — `Cmd + Shift + 4` for a region, or `Cmd + Shift + 5` for a window.
- **Windows** — `Win + Shift + S` (Snipping Tool).
- **Linux** — `Shift + PrtSc`, or use GNOME Screenshot / Spectacle.
- **Any OS, for the mobile shot** — open DevTools (`F12`), toggle the device toolbar
  (`Cmd/Ctrl + Shift + M`), pick iPhone 14, then use the ⋮ menu → *Capture screenshot*.

Tip: search for a city with interesting weather (somewhere with a thunderstorm or snow) — the page
background tints to match the conditions, which shows the app off better than a clear day.
